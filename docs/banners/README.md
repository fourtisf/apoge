# Apoge announcement banners

Premium 2400×1350 (16:9) banners for X / Telegram, matching the site's dark +
gold aesthetic. Regenerate after editing copy in `make-banners.mjs`:

```bash
CHROME_BIN=/path/to/chrome node docs/banners/make-banners.mjs
```
